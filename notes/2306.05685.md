## 요약

이 논문은 대규모 언어모델(LLM)을 평가자로 쓰는 "LLM-as-a-judge" 접근을 체계적으로 검토하고, 인간 선호와의 일치도를 두 개의 벤치마크로 검증한다. 저자들은 MT-bench(다중 턴 질문 80개)와 Chatbot Arena(익명 대전 플랫폼, 약 3만 표)를 소개하고, GPT-4 등 강력한 LLM이 위치·장황함·자기강화 편향과 수학·추론 채점의 한계를 가진다고 분석한다(§3.3). 이 편향들은 답변 순서 바꾸기, CoT, 참조 정답 제공 등 간단한 완화책으로 일부 해소된다(§3.4). GPT-4 판단은 통제된 전문가 투표와 크라우드 투표 모두에서 인간과 80%를 넘는 일치율을 보이며, 이는 인간 간 일치 수준과 같다(§4.2, Table 5·6). 따라서 LLM-as-a-judge는 비용이 큰 인간 평가를 대체할 확장 가능하고 설명 가능한 방법이며, 기존 능력 벤치마크와 병행 쓰는 하이브리드 평가가 권고된다(§5).

## 핵심 주장

1. GPT-4 판사는 인간 선호와 80%를 넘는 일치율을 보이며 인간 간 일치 수준과 같다 (§4.2, Table 5, Table 6).
2. LLM 판사에는 위치·장황함·자기강화 편향과 수학/추론 채점 한계가 있으나, 위치 바꾸기·CoT·참조 정답 제시로 상당 부분 완화된다 (§3.3, §3.4, Table 2, Table 4).
3. 인간 선호 기반 벤치마크(MT-bench)와 전통적 능력 벤치마크(MMLU 등)는 서로 다른 모델 특성을 드러내므로 둘을 함께 써야 한다 (§5, Table 9).

## 실험 설정

- **데이터셋**: MT-bench — 8개 카테고리(작성, 롤플레이, 추출, 추론, 수학, 코딩, 지식 I(STEM), 지식 II(인문/사회))당 10개씩 수작업으로 만든 2턴 질문 80개 (§2.2). Chatbot Arena — 사전 정의 질문 없이 수집한 익명 대전 약 30K 표(운영 1개월) (§2.3). 동의율 분석에는 MT-bench 약 3K 표와 Arena 30K 중 무작위 표본 3K 단일 턴 표를 사용 (§4.1).
- **비교 대상(베이스라인)**: 금금標準인 인간 평가 — MT-bench는 대학원생 수준의 전문 라벨러 58명(인간 간 일치 포함), Arena는 2114개 고유 IP의 크라우드 라벨러 (§4.1). 판사 유형별 비교: GPT-4 쌍대비교(G4-Pair), GPT-4 단일 채점(G4-Single), GPT-3.5, Claude, 인간, 인간 다수결(Human-M) (Table 5, 6, 14). 무작위 기준치는 S1에서 33%, S2에서 50% (Table 5).
- **평가 지표**: 두 판사 유형 간 일치율(서로 다른 두 판사가 무작위 질문에서 동일한 선택을 할 확률), 평균 승률(무승부 포함/미포함 두 버전) (§4.1, §D.3). 일치율 설정 S1은 무승부·비일치를 무승부로 집계, S2는 무승부 표본만 포함 (Table 5). 위치 편향은 답변 순서를 바꿨을 때 결과가 일치하는 비율(consistency)로 측정 (Table 2).
- **모델**: 답변 생성 6개 모델 — GPT-4, GPT-3.5, Claude-V1, Vicuna-13B, Alpaca-13B, LLaMA-13B (§4.1). Arena 표본에는 Koala-13B, Dolly-12B 등 추가 (§4.1). 판사 성능 비교에는 Claude-v1, GPT-3.5, GPT-4 (Table 2, 3), 오픈소스 판사 실험에는 zero-shot 및 Arena 데이터로 파인튜닝한 Vicuna-13B (Appendix F). 전통 벤치마크 비교는 MMLU(5-shot), TruthfulQA MC1(0-shot), MT-bench 점수(GPT-4 단일 채점, 턴당 10점 만점, 80×2=160 평균) (§5, Table 9).

## 발표 때 받을 만한 질문 5개

1. **"인간 간 일치 81%보다 GPT-4–인간 일치 85%가 높은 것은 모순 아닌가?"**
   - 답의 실마리: 인간 간 일치는 두 무작위 인간 쌍의 확률이라 낮게 잡힐 수 있고, D.3에서 human-majority 기준 상한(90%)을 따로 정의해 보완했다 (§4.2, §D.3, Table 14).

2. **"위치 편향 완화책으로 순서를 두 번 호출하면 비용이 두 배 아닌가?"**
   - 답의 실마리: 보수적 방식은 양쪽 순서에서 모두 선호될 때만 승자를 선언하고 불일치하면 무승부로 두며, 공격적으로는 순서를 무작위로 배정하는 대안도 제시된다 (§3.4).

3. **"GPT-4가 자기 답변을 유리하게 봐도 되는 자기강화 편향은 확인된 것 아닌가?"**
   - 답의 실마리: GPT-4는 자기 승률이 10%p 높지만 다른 모델도 선호하고 GPT-3.5는 자기 편향이 없어, 데이터 부족·차이 작아 판단 유보이며 통제 실험은 스타일 변경이 품질을 바꿔 어렵다 (§3.3, Figure 2(b)).

4. **"CoT로 충분히 해결 안 되나, 굳이 참조 정답이 필요한 이유는?"**
   - 답의 실마리: CoT에서도 판사가 주어진 오답과 같은 실수를 하며 맥락에 끌려가고, 참조 정답 제시 시 실패율이 14/20에서 3/20으로 떨어진다 (§3.4, Table 4, Figure 14).

5. **"쌍대비교는 모델 수가 늘면 사분면ically 커지는데 왜 단일 채점을 쓰는가?"**
   - 답의 실마리: 단일 채점은 확장성·일관된 내부 기준에서 우수하되 미묘한 차이 판별과 점수 변동은 약해, 무승부 표가 많아지며 보완적으로 함께 쓰인다 (§3.1, §4.2, Table 5).
